# Gestor de tareas académicas

Tarea de Programación Orientada a Objetos II.

Realicé este proyecto en C# con Windows Forms para practicar el uso de controles y eventos en una interfaz gráfica.

## ¿Qué permite hacer?

- Escribir una actividad y agregarla a la lista.
- Evitar que se agreguen tareas vacías o repetidas.
- Seleccionar y eliminar una actividad.
- Limpiar toda la lista, con una confirmación antes de borrarla.
- Ver cuántas actividades hay registradas.

## Cómo ejecutar

1. Abrir `GestionTareasPendientes.sln` en Visual Studio 2022.
2. Tener instalado el desarrollo de escritorio .NET y el SDK de .NET 8.
3. Presionar F5.

La información solo se guarda mientras la ventana permanece abierta. No se utilizó una base de datos porque no la pide el ejercicio.
